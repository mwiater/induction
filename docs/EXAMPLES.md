# Pipeline Examples

The examples below are grouped by the primary capability or workflow they demonstrate. Each group links to its own pipeline filename list.

## Document

These pipelines ingest PDF or other document inputs and turn them into summaries, structured evidence, or normalized records. Use them for document review, extraction, batch processing, or comparing several source documents at once. See the [document example files](EXAMPLES-DOCUMENT.md).

## Vision / Image

These pipelines analyze visual content, from a single image to batches or combined image sets, and demonstrate configurable model parameters. Use them for visual inspection, image comparison, cataloging, or testing multimodal model behavior. See the [vision and image example files](EXAMPLES-VISION-IMAGE.md).

## Image Text / OCR

These pipelines read text embedded in images and transform the OCR result into a structured or validated record. Use them for scanned forms, signs, archival indexing, accessibility descriptions, and document intake. See the [OCR example files](EXAMPLES-IMAGE-TEXT-OCR.md).

## MCP Tools

These pipelines demonstrate model-driven calls to MCP tools, including discovery, chained lookups, web research, JSON endpoint inspection, and source comparison. Use them when a pipeline needs live external data or tool-assisted investigation. See the [MCP tool example files](EXAMPLES-MCP-TOOLS.md).

## Decision Routing

These pipelines use bounded decisions to select later work conditionally, including single-branch routing and multi-level decision trees. Use them for triage, classification, policy workflows, and controlled branching. See the [decision-routing example files](EXAMPLES-DECISION-ROUTING.md).

## Knowledge Graph

This pipeline profiles a document corpus, extracts observations, resolves entity candidates, and produces structured relationships. Use it as a starting point for corpus indexing, entity resolution, and graph-oriented research workflows. See the [knowledge-graph example files](EXAMPLES-KNOWLEDGE-GRAPH.md).

## Prompt Optimization

This pipeline generates a baseline answer, rewrites the request into an optimized prompt, produces a second answer, and evaluates the difference. Use it to experiment with prompt quality, task-specific instructions, and response improvements. See the [prompt-optimization example files](EXAMPLES-PROMPT-OPTIMIZATION.md).

## Text

These text-only pipelines pass information through multiple language-model steps for extraction, transformation, analysis, and structured output. Use them for support writing, meeting notes, explanations, policy editing, and incident summaries. See the [text example files](EXAMPLES-TEXT.md).

## Generated / Task Management

This generated example shows how a task-management API workflow can be represented as a pipeline. Use it as a reference when evaluating or generating pipelines for application-specific operations. See the [generated and task-management example files](EXAMPLES-GENERATED-TASK-MANAGEMENT.md).
